# RouteLens v7.2.2 · 空白拖窗与减少重复重绘

现在可以按住顶部导航周围、页面外侧留白和普通面板空白处移动整个窗口。最外侧边带和右下角拖拽柄继续用于缩放；按钮、输入框、表格、地图和滚动条保留原操作。

减少重复的圆角区域创建、国家列和国家排行重绘、相同按钮/面板样式刷新。拖窗和缩放期间延后主窗口界面刷新，松手后显示最新数据，后台采样继续。

验证通过：90 项空白拖动边界检查、29 项重绘与刷新调度检查，以及窗口、分页和动画回归。20 次相同数据/样式刷新在对应测量项中为零重绘。此结果证明减少了重复工作，不代表已测得固定帧率。桌面工具初始化失败，本次未完成空白拖窗的实际鼠标端到端验证，详情见 docs/WINDOW-DRAG-RENDER.md。

下载 `RouteLens-Windows-v7.2.2.zip` 或 `RouteLens.exe`，关闭旧版后运行；文件版本为 7.2.2.0。`SHA256SUMS.txt` 提供校验值。需要 Windows 10/11 与 .NET Framework 4.8。

行为调查仍默认关闭，流量阈值只提供待核查线索，不能单独确认感染、DDoS 或整机安全。
