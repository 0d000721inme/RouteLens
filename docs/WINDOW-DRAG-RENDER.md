# 空白拖动整窗与重绘优化

v7.2.2 区分两种操作：页面外侧留白、顶部导航周围及普通面板空白处拖动时移动整个窗口；最外侧缩放边带和右下角拖拽柄继续改变窗口大小。静态说明文字也可作为移动区域。

`WindowDragSurface` 在主窗口的 UI 线程过滤客户区左键按下，把符合条件的目标交给 Windows 的 HTCAPTION 移动处理。它只接受明确的普通面板、布局容器、静态 Label 和属于主窗口的嵌入 Form；交互控件及其内部区域、禁用子控件覆盖处、其他顶层窗口不参与。页签内容中的交互区域和表格空行仍由原控件处理。无需给每个新建页面重复挂接事件；关闭或直接释放主窗口时解除过滤器。

按钮、输入框、链接、地图、表格、滚动条与原有品牌区拖动/双击处理保留各自操作。底层的原生移动与缩放样式沿用 v7.2.1。

## 重绘优化

- 相同尺寸、DPI 和窗口状态不再重复创建圆角 Region，也不重复调用设置窗口区域。
- 拖动/缩放期间延后主窗口的连接界面刷新，后台快照接收与调查更新继续，结束后显示最新数据。
- 国家列不再每轮整列重画；文字仍按变化更新，旗帜变化时只使对应单元格失效。
- 国家排行仅在统计、选择或旗帜变化时重绘。新旗帜异步加载完成后仍会在下一次数据更新中显示。
- 按钮和圆角面板属性赋相同值时不再重绘；已存在的世界地图底图缓存保持原实现。

这些修改减少了无效重绘，仍使用 WinForms/GDI+。未迁移到 GPU 渲染框架，也没有测得或承诺固定帧率。

## 2026-11-04 验证

- `RunWindowDragChecks.ps1`：90 项，九页实际留白 HWND、允许区域、交互控件排除、其他窗口隔离及释放。
- `RunRenderSchedulingChecks.ps1`：6 项；20 次相同刷新没有圆角区域替换、没有国家单元格重画；一次缩放只替换一次 Region；拖动期间接受新快照，结束后补上最新界面。
- `RunRenderInvalidationChecks.ps1`：23 项；20 次相同国家数据和样式赋值零重绘，变化数据/选择/异步旗帜继续重绘，并检查更新后的像素。
- 原有窗口 338 项、分页 227 项、动画 10 项通过；原生页面渲染截图检查布局。

本次桌面输入工具及备用入口均在初始化时报 `failed to write kernel assets`，重置也未恢复。因此未完成本版空白拖窗的实际鼠标端到端验证，也没有对拖窗流畅度做帧时间测量。独立交互程序新增 `Move=` 原生移动命令计数、留白坐标及目标控件，便于后续复核窗口位置改变且尺寸不变。测试使用虚构数据。
