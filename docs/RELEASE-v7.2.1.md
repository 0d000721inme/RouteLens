# RouteLens v7.2.1 · 修复右下角实际拖拽缩放

修复 v7.2.0 中鼠标放到右下角后仍无法调整大小的问题。主窗口现在启用 Windows 原生缩放处理，并提供更容易点中的 24×24 DIP 右下角拖拽柄。四边缩放、圆角、分页和过渡动画继续保留。

修复过程中也检查了初次显示、连续最大化/还原和最小化/还原，避免边框尺寸补偿造成窗口大小漂移。默认最小尺寸仍为 1040×720（按 DPI 调整）。

已在 Windows 10 上用真实鼠标输入验证同一窗口连续缩小、放大、再缩小，以及右边缘调整宽度；读取实际窗口尺寸与 Windows 缩放事件确认结果。窗口、分页与动画回归检查通过。Windows 11 与混合 DPI 多显示器尚未实机验证。

下载 `RouteLens-Windows-v7.2.1.zip` 或单文件 `RouteLens.exe`，`SHA256SUMS.txt` 提供校验值。需要 Windows 10/11 与 .NET Framework 4.8。请关闭旧版后运行新版；EXE 文件版本为 7.2.1.0。

行为调查功能保持原有范围：默认关闭，流量阈值只产生待核查线索，不能单独确认感染、DDoS 或整机安全。
