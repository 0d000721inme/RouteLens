# RouteLens v7.3.1 · 地图动画与窗口缩放优化

地图详情页打开时会播放一次南通↔香港方向动画，并明确标注为演示路线，不代表实际连接或流量。选中连接只有在端点可定位且采样到上传或下载速率时才播放实测方向；没有可比较的速率时，可手动播放演示动画。若 Windows 动画效果关闭，地图用静态方向箭头表示方向。

地图缩放时复用现有图层，待用户停止缩放后再更新完整内容。主窗口调整大小期间显示已有画面的缩放预览，结束后恢复完整布局，并在尺寸变化后适配内容。窗口移动不触发缩放预览，画面捕获不可用时会回退到原有渲染路径。

## 性能说明

缩放卡顿与 WinForms/GDI+ 同步绘制及 UI 线程上的布局级联有关，特别是窗口尺寸变化时多个嵌套布局容器同步响应。问题不是 C# 语言本身造成的。当前改动减少缩放期间的重复布局和绘制，但不会让应用达到固定帧率。两轮基准检查各包含 48 次连续尺寸更新。连接页中位耗时为 7.2–10.8 毫秒、p95 为 28.4–31.5 毫秒；地图页中位耗时为 7.2–7.7 毫秒、p95 为 28.1–28.5 毫秒。最新一轮地图自身的缩放预览平均约 15.9 毫秒，最高约 22.2 毫秒。设备、分辨率、DPI 和当前页面内容会影响实际表现。

## 验证

构建及地图方向（35 项）、地图缩放缓存（156 项）、主窗口缩放（48 次连续尺寸更新）、窗口边缘处理（338 项）、空白区域拖动（90 项）、渲染调度（8 项）、分页（269 项）和页面过渡（10 项）检查通过。窗口边缘检查在重试后通过；一次初次运行被测试桌面上的另一个窗口遮挡。尚未完成真实鼠标拖拽验证。程序化尺寸变化结果不能替代不同设备上的实际拖拽体验检查。

需要 Windows 10/11 和 .NET Framework 4.8。地图位置为国家或城市代表点，动画只表达方向，不能证明应用数据经过地图上显示的每个地点。
