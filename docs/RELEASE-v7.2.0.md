# RouteLens v7.2.0 · 分页、行为调查与圆角缩放

- 顶部九个入口改为主窗口内翻页，当前页高亮，支持 Ctrl+Tab / Ctrl+Shift+Tab，保留筛选和未保存草稿。
- 页面切换加入约 170 毫秒淡入动画；遵循 Windows 动画设置，连续切页及缩放时及时结束旧动画。
- 修复子控件遮挡缩放边缘的问题：四条边、四个角均有缩放命中区域。普通窗口使用圆角，最大化填满工作区，还原保留位置和尺寸。
- 新增原生行为调查页，支持持续上传线索、手动连接快照、复核备注及默认隐藏敏感字段的 JSON 导出。自动观察默认关闭，记录仅存于本次运行内存。

下载 `RouteLens-Windows-v7.2.0.zip` 并解压运行 `RouteLens.exe`，或直接下载单文件 EXE。需要 Windows 10/11 与 .NET Framework 4.8，不需要 Python、Node.js 或抓包驱动。`SHA256SUMS.txt` 提供两个发行资产的校验值。源码也包含在 ZIP 内。

验证：Windows 10 上窗口回归 289 项、分页 227 项、动画 10 项、行为调查 69 项、调查界面 46 项、流量 54 项；提醒、历史、网卡、系统时间线、外部记录、DNS、离线查询及证据检查均通过。截图已检查普通与最小窗口布局。桌面捕获工具超时，未完成可视化鼠标拖拽验证；Windows 11 与混合 DPI 多显示器尚未实机验证。

能力范围：持续上传阈值用于提供待核查线索，不能单独确认感染、DDoS 或整机安全。没有新增全机 ETW 采集、内存扫描或驱动检测；Clash 外流量、短连接、低流量活动和潜伏程序仍可能遗漏。
