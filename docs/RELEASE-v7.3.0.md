# RouteLens v7.3.0 · 主题、站点用量与连接路径

## 新功能

- 右上角日间/夜间主题切换，带平滑的皮肤转场，记住当前 Windows 用户的选择，并遵循系统动画偏好。
- 顶栏显示本机 Clash Verge / Mihomo 可读到的订阅额度、已用量和剩余量。额度仅来自本机配置或内核接口，不上传订阅资料。
- 顶栏按网站品牌色显示本次运行中观察到的今日流量，并分开显示代理、直连和未判定。点击可检查流量明细并选择可用套餐。应用退出后清除今日站点累计。
- 可选的单程序高速下载提醒会在连接页短暂显示并调用 Windows 通知。默认关闭，速度和时长条件可自行调整。提醒只是调查线索。
- 可从所选连接打开连接路径地图。路线页展示 Clash / Mihomo 元数据和手动 ICMP 逐跳结果，并按已测到的上传/下载方向播放地图动画。
- 新增 RouteLens 应用图标和窗口图标。

## 观察边界

套餐剩余量不代表服务商实时账单，刷新取决于本机 Clash Verge / Mihomo 暴露的数据。今日流量只反映本次运行中连续采样且带字节计数的 Clash 连接增量，可能遗漏短连接和未计速流量，不代表全机总量。

连接路径中的 ICMP 探测从本机独立发起，不会沿用应用的完整代理连接。代理隧道内部路径通常不可见。ICMP 逐跳响应、地理位置和动画都不能证明应用数据包经过地图上显示的每个国家或城市。观察不到路径也不代表连接异常。

高速下载提醒仅用于核查，无法单独确认程序受感染、电脑参与 DDoS，或整机安全。Windows 通知依赖系统通知服务和应用通知权限。

## 验证

本发布包由仓库中的 `build.ps1` 构建。测试脚本包含主题切换、订阅数据解析、日内站点累计、站点明细、高速下载提醒、ICMP 逐跳及真实回环端到端连接路径检查。测试不会访问真实订阅或上传网络活动。

需要 Windows 10/11 和 .NET Framework 4.8。行为观察、提醒和路径探测仅在用户主动启用或启动时运行。
