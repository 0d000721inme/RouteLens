# 主窗口分页与过渡动画

2026-11-01 更新。本次保留 RouteLens 现有配色、数据流程及行为调查功能，将顶部九个入口改成主窗口中的页面导航。

## 交互

- 顶部导航始终保留，点击后切换下方完整内容，当前页蓝色高亮；不再为这些主功能打开模态窗口。
- 每个功能页面在本次运行中复用。连接筛选、页面筛选、尚未应用的提醒设置、调查复核草稿在来回切换后保留。
- “返回连接”回到连接页，不销毁当前功能页。调查未保存草稿在退出整个程序前仍会提示。
- Ctrl+Tab / Ctrl+Shift+Tab 循环前后翻页；Ctrl+F 可聚焦当前页可见的搜索框。
- 页面过渡约 170 毫秒，使用缓出的淡入效果；连续切换取消旧动画，窗口尺寸变化结束动画。

动画遵循 Windows 的客户端区域动画设置。高对比度、远程桌面、捕获失败或页面超过 200 万像素时直接显示目标页面。最多两个过渡位图保存在内存，不落盘，完成或中断后立即释放。导航语义与动画独立，动画降级不会阻止切页。

## 生命周期

主窗口采样仍持续运行。历史、证据、调查、地图和离线地区页隐藏时停止界面刷新，重新显示时刷新。实时流量页继续保留其有界的趋势及目标采样，隐藏时跳过表格重绘。主动 DNS 测试仍只由用户开始，退出程序会取消尚未完成的测试。

具体工具的文件选择、连接详情、系统日志及外部记录等操作窗口保留各自用途；顶部主功能页面均在主窗口内切换。

## 验证

- RunPageNavigationChecks：覆盖九个页面、选中高亮、主窗口保持可操作、页面复用、草稿与筛选保留、提醒保存不关闭、返回连接、快捷键、1040×720 最小布局、快速切换及缩放、关闭后资源释放。
- RunPageTransitionChecks：在本机动画设置开启的情况下验证实际动画启动、混合中间帧、结束清理、快速替换、缩放取消和异常尺寸降级。
- 既有 InvestigationUiChecks、InvestigationChecks、TrafficTrackerChecks、EvidenceMonitorChecks 通过。
- 已查看原生 WinForms 的默认与最小窗口截图；验证使用虚构数据，未发起主动 DNS 测试或上传网络记录。

源码仍为 .NET Framework / WinForms，无新增第三方依赖。运行 build.ps1 可重建。
